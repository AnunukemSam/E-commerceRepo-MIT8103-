# MIT 8103 — Advanced Database Systems

**Individual Practical Database Portfolio**

**Case study:** E-commerce and Inventory Management System (simulated electronics retailer)

**Main database:** PostgreSQL 18

**Repository status:** Public, following lecturer instructions.

## Project scope

This is a database-focused academic project that models customers, categories, products, orders, order items and simulated payments. It does not process real payments and does not contain a customer-facing web application.

## Portfolio roadmap

1. **Portfolio 1 — Database Design and Modelling:** Six-table ER diagram, relational schema, constraints, normalisation, PostgreSQL implementation and supporting evidence. Local implementation reported complete; uploaded evidence pending.
2. **Portfolio 2 — Query Processing and Optimisation:** SQL queries, execution plans, indexing and performance observations.
3. **Portfolio 3 — Transactions and Concurrency:** Commit, rollback, isolation and concurrency control.
4. **Portfolio 4 — NoSQL and Advanced Data Models:** MongoDB implementation based on the same business scenario.
5. **Portfolio 5 — Distributed and Cloud Databases:** Small-scale architecture/implementation exercise addressing availability, consistency and related tradeoffs.

## Evidence status

The database has been implemented and tested locally. The SQL schema export from the student's own PostgreSQL instance, ER diagram, screenshots and accompanying design report must be reviewed and added here.

**Important:** Reference SQL files and illustrative results are not substitutes for evidence captured from the actual database.

## Public repository safety

Use only fictional sample data. Do not commit passwords, connection strings containing secrets, API keys, real customer information, or unredacted screenshots of private account details.

ChatGPT has been used to assist with learning, database design discussions and drafting project documentation. All scripts, results and explanations should be independently reviewed and verified before submission.
